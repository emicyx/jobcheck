## 安装（开发者模式）

1. 打开 Chrome/Edge 的 `chrome://extensions/`
2. 右上角打开「开发者模式」
3. 点「加载已解压的扩展程序」，选择本目录（`extension/`）
4. 升级插件后（含从 ≤0.3 升到 0.4）：在扩展卡片上点「重新加载」，并**刷新所有相关页面**——目标网站页（网络捕获只在页面加载前注入）和平台页（重载后旧内容脚本与后台断开，不刷新则向导会误判插件状态；新版会明确提示「请刷新本页」）

## 工作原理

- 内容脚本只注入平台自身页面（默认 `http://localhost:5173`，上线后需在 `manifest.json` 的 `content_scripts.matches` 里加上正式域名）
- 平台页点击「去登录」→ 扩展新开标签页打开招聘官网登录页 → 你正常登录（短信验证码到自己手机）
- 扩展监听 Cookie 变化：门户配置的会话 Cookie 齐备后，自动收集该域 Cookie，凭一次性 `bind_token` 回传平台完成激活，然后自动关闭登录页
- **采样（v0.4 起，M4）**：`net-capture.js` 以 MAIN world 内容脚本在 `document_start` 包装页面的 `fetch`/`XMLHttpRequest`，把 JSON 请求-响应对缓存在页面自己的 JS 上下文里（`window.__jcNet`，环形缓冲，同页去重）。你在「我的投递」页点插件图标 →「采集当前页面」时，这些缓冲连同裁剪后的 DOM 一起凭一次性采样 token 提交到平台，用于自动生成该网站的追踪配方
- **只读**：包装只记录不修改；不执行任何写操作请求

## 隐私

- Cookie 经 HTTPS 直接送往你自己的平台实例并 AES-256-GCM 加密存储，不经过任何第三方
- 网络捕获缓冲**只存在于当前页面**，你点「采集当前页面」之前绝不离开浏览器；页面关闭即消失
- 平台侧（进入 LLM 前）会对手机号/身份证/邮箱打码；采样仅覆盖你显式触发采集的那一个页面

## 扩展同步（v0.5，REFACTOR_PLAN 新架构·已转正）

**用户旅程**：平台「设置 → 扩展同步」生成 6 位配对码 → 插件 popup 输入配对 →
到招聘站「我的投递」页点插件「**同步当前页**」→ 后端现场解析 → **卡片出现/更新、
该站连接建立**。Cookie 永不离开浏览器；已连接站点插件每 3 小时静默刷新（隐藏标签页回访）。
浏览站点本身不产生任何上报（0.6.0 起访问时自动采集已移除）。

- **配对码**：平台「设置 → 扩展同步」页一键生成（也可控制台
  `fetch('/api/ext/pair-code',{method:'POST',credentials:'include'})`），
  10 分钟有效、一次性；popup 空闲面板输入配对即完成绑定（Bearer token 存本地，只发自己的平台）
- **解密后捕获（v0.5.3）**：部分站点接口响应体加密（星环 `app.mokahr.com` 实盘：
  `{"data":密文,"necromancer":…}`，网络层只见密文），明文解密后必经 `JSON.parse`——
  net-capture 以只读包装捕获解密对象入缓冲。**宽松形状门 + 内容哈希分槽保留最近
  4 个不同对象**（「像不像投递」的判断全部交给后端 heuristics + 职位广告键过滤，
  扩展不做词典预判），带节点预算防热路径开销
- **飞书系站点特例**：记录页 SSR 直出、初始不发列表 XHR（缓冲恒空），采集时
  （手动/定时回访均同）用已知平台探测规格补数据（契约同采样探测：
  POST `/api/v1/search/user/applications` + CSRF 头，有 `atsx-csrf-token` 时才探测）
- **资源回放兜底**：`performance resources` 筛出的接口类候选（未进缓冲时）GET→POST{} 递进
  重放——Moka 列表接口 GET→405 已实盘证伪，空 JSON 体 POST 是北森已知契约
- **PII 清洗**：上报前剔除常见身份键（Name/Mobile/Email/Phone/身份证号等，值替换占位符）
- **上报队列**：`chrome.storage` 持久化，失败退避重试（1min→5min→30min→2h，12 次放弃）；
  MV3 service worker 被杀不丢数据（每分钟 alarms 冲刷）
- **未登录检测**：URL/响应体特征 → `login_suspect` 上报，后端据此标连接 stale
- API 默认走平台前端代理 `http://localhost:5173`（与采样提交同路径）；可在扩展
  `chrome.storage.local` 写 `jcApiBase` 覆盖
